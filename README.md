# AI Error Explainer

An AI-powered web application that explains programming errors and provides possible solutions.

## Technologies Used

- Java
- Spring Boot
- Ollama
- Qwen 2.5
- HTML
- CSS
- JavaScript

## How It Works

1. User enters a programming error.
2. The Spring Boot backend receives the error.
3. The application sends the error to Ollama.
4. Qwen 2.5 analyzes the error.
5. The AI-generated explanation and solution are displayed to the user.

## Features

- Explains programming errors in simple language
- Provides possible solutions
- Uses a locally running AI model
- Simple web interface

## How to Run

1. Install Java and Ollama.
2. Download the Qwen 2.5 model using Ollama.
3. Run the Spring Boot application.
4. Open the application in a browser.
5. Enter a programming error and click **Explain Error**.
